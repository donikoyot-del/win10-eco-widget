# 🔋 Windows 10 Eco Power Widget

Компактний напівпрозорий віджет для швидкого перемикання Windows 10 в економний режим прямо з робочого столу.

## ✨ Особливості
- **Ледь помітний язичок** біля правого краю екрана у режимі спокою.
- **Автоматична поява** та плавна анімація при наведенні курсору миші.
- **Розмір 3х3 см** — мінімалістичний квадрат з великою іконкою батарейки.
- **Перемикання в 1 клік** між режимом економії (іконка стає зеленою) та збалансованим.

## 🚀 Як запустити
1. Переконайтеся, що на комп'ютері встановлено **Python 3**.
2. Запустіть файл через консоль:
   ```bash
   python widget.py
   ```
